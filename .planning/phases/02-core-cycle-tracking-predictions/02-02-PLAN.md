  <behavior>
    **Tier 1 (SimpleAveragePrediction):**
    - predict([28]) with lastPeriodStart=2026-03-01, periodLength=5 -> nextPeriodStart=2026-03-29 (28 days later)
    - predict([28, 30, 26]) -> uses rolling average (28) -> nextPeriodStart = lastPeriod + 28
    - predict([28, 28, 28, 28]) -> confidence near 90% (zero variance, capped at 90 for Tier 1)
    - predict([25, 35, 28, 32]) -> confidence lower (~60-70%) due to high variance
    - Always includes fertileWindowStart (ovulationDay-5), fertileWindowEnd (ovulationDay), ovulationDate
    - tier field is always 1
    - confidence is always between 40 and 90

    **Tier 2 (ARIMAPrediction):**
    - predict([28,29,28,30,28,29]) with 6 data points -> produces valid prediction with tier=2
    - Uses manual ARIMA parameters p=1, d=1, q=0 (NOT AutoARIMA -- per research pitfall 2)
    - Calls arima.destroy() after prediction to free WebAssembly memory
    - confidence between 50 and 95 (Tier 2 cap)
    - If ARIMA prediction is unreasonable (< 18 or > 45 days), falls back to Tier 1 result
    - tier field is always 2

    **Tier 3 (LSTMPrediction stub):**
    - predict() delegates to ARIMAPrediction (Tier 2) internally
    - tier field is 3 (reports as Tier 3 even though using Tier 2 math)
    - Does NOT import @tensorflow/tfjs-node (not installed)

    **Factory (getPredictionEngine):**
    - getPredictionEngine(1) -> returns SimpleAveragePrediction instance
    - getPredictionEngine(5) -> returns SimpleAveragePrediction instance
    - getPredictionEngine(6) -> returns ARIMAPrediction instance
    - getPredictionEngine(11) -> returns ARIMAPrediction instance
    - getPredictionEngine(12) -> returns LSTMPrediction instance (stub)
    - getPredictionEngine(50) -> returns LSTMPrediction instance (stub)

    **All tiers:**
    - All return CyclePrediction with: nextPeriodStart, nextPeriodEnd, ovulationDate, fertileWindowStart, fertileWindowEnd, confidence (0-100), tier (1|2|3)
    - Fertile window = ovulationDay-5 to ovulationDay; ovulation = cycleLength - 14
  </behavior>
