    Add Phase 2 database models to the existing Prisma schema:

    **CycleLog model:**
    - id: String @id @default(uuid())
    - profileId: String (FK to Profile, onDelete: Cascade)
    - startDate: DateTime @db.Date (DATE not TIMESTAMP -- timezone-safe)
    - endDate: DateTime? @db.Date (nullable until period ends)
    - flowIntensity: FlowIntensity enum (light, medium, heavy, spotting)
    - createdAt: DateTime @default(now())
    - updatedAt: DateTime @updatedAt
    - Index: @@index([profileId, startDate(sort: Desc)])
    - Table name: @@map("cycle_logs")

    **SymptomLog model:**
    - id: String @id @default(uuid())
    - profileId: String (FK to Profile, onDelete: Cascade)
    - date: DateTime @db.Date
    - category: SymptomCategory enum (physical, mood, discharge, lifestyle)
    - symptoms: String[] (PostgreSQL array column)
    - notes: String? /// @encrypted (field-level encryption for sensitive notes)
    - createdAt: DateTime @default(now())
    - updatedAt: DateTime @updatedAt
    - Unique constraint: @@unique([profileId, date, category]) -- one log per category per day per profile
    - Index: @@index([profileId, date(sort: Desc)])
    - Table name: @@map("symptom_logs")

    **Prediction model:**
    - id: String @id @default(uuid())
    - profileId: String (FK to Profile, onDelete: Cascade)
    - nextPeriodStart: DateTime @db.Date
    - nextPeriodEnd: DateTime @db.Date
    - ovulationDate: DateTime @db.Date
    - fertileStart: DateTime @db.Date
    - fertileEnd: DateTime @db.Date
    - tier: Int (1, 2, or 3)
    - confidence: Float (0-100)
    - cycleLengthUsed: Int
    - createdAt: DateTime @default(now())
    - Index: @@index([profileId, createdAt(sort: Desc)])
    - Table name: @@map("predictions")

    **Enums:**
    - FlowIntensity: light, medium, heavy, spotting
    - SymptomCategory: physical, mood, discharge, lifestyle
