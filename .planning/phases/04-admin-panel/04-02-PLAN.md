  <action>
    **Estimated effort: 6-8 developer-hours**

    1. Create `packages/api/src/services/admin-users.service.ts`:
       - `listUsers(query: UserListQuery)`: Paginated user list with search (email contains), sort, filter by role. Returns `{ data: AdminUser[], meta: { page, limit, total, totalPages } }`. Select: id, email, role, isActive, createdAt, lastLoginAt, _count.profiles. Never return password hash.
       - `getUserDetail(userId: string)`: Full user view including profile list (names, relation types, created dates), account creation date, last login, role, suspension status. Include profile count and last activity date.
       - `suspendUser(userId: string)`: Set `isActive = false`. Cannot suspend self. Cannot suspend another superAdmin (only another superAdmin can, and not themselves).
       - `reactivateUser(userId: string)`: Set `isActive = true`.
       - `deleteUser(userId: string)`: Soft delete or hard delete per privacy policy. Delete all associated profiles and data (cascade). Cannot delete self.
       - `resetPassword(userId: string)`: Generate temporary password, hash with argon2, update user record, return temporary password (to display once). OR trigger password reset email flow.

    2. Create `packages/api/src/routes/admin/users.routes.ts`:
       - `GET /api/admin/users` -- list users, requireRole('superAdmin'), validate query with userListQuerySchema
       - `GET /api/admin/users/:id` -- user detail, requireRole('superAdmin')
       - `PATCH /api/admin/users/:id/suspend` -- suspend user, requireRole('superAdmin')
       - `PATCH /api/admin/users/:id/reactivate` -- reactivate user, requireRole('superAdmin')
       - `DELETE /api/admin/users/:id` -- delete user, requireRole('superAdmin')
       - `POST /api/admin/users/:id/reset-password` -- reset password, requireRole('superAdmin')
       - All routes use verifyJWT -> requireRole -> validate -> handler chain

    3. Register user routes in admin router.
  </action>

    - PATCH suspend/reactivate toggles user isActive flag
    - Cannot suspend or delete self (returns 400)
