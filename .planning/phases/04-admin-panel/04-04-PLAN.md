  <action>
    **Estimated effort: 6-8 developer-hours**

    1. Create `packages/api/src/services/admin-content.service.ts`:
       - `listArticles(query: PaginationQuery & { status?: ArticleStatus, categoryId?: string })`: Paginated article list. Select: id, slug, titleEn, titleBn, status, categoryId (with category name), cyclePhases, authorId (with author email), publishedAt, createdAt, updatedAt. Support sorting by title, status, createdAt, publishedAt.
       - `getArticle(id: string)`: Full article including bodyEn, bodyBn (Tiptap JSON), all metadata, category object, author email.
       - `createArticle(data: CreateArticleInput)`: Create new article. Fields: slug (auto-generate from titleEn if not provided, using slugify logic), titleEn, titleBn, bodyEn (Tiptap JSON string), bodyBn (Tiptap JSON string), categoryId, tags (string array), cyclePhases (string array: follicular/ovulatory/luteal/menstrual), status (DRAFT default). Set authorId from req.user.id.
       - `updateArticle(id: string, data: UpdateArticleInput)`: Partial update. If status changes to PUBLISHED, set publishedAt to now(). If status changes from PUBLISHED to DRAFT, clear publishedAt.
       - `deleteArticle(id: string)`: Hard delete article. Return success boolean.
       - `listCategories()`: Return all content categories (id, name, slug, articleCount). Used for category dropdown in editor.
       - `createCategory(data: { name: string, slug: string })`: Create new category. Super Admin only.
       - `deleteCategory(id: string)`: Delete category if no articles assigned. Returns error if articles exist.

    2. Create `packages/api/src/routes/admin/content.routes.ts`:
       - `GET /api/admin/content/articles` -- list articles, requireRole('superAdmin', 'contentAdmin')
       - `GET /api/admin/content/articles/:id` -- get article, requireRole('superAdmin', 'contentAdmin')
       - `POST /api/admin/content/articles` -- create article, requireRole('superAdmin', 'contentAdmin'), validate body with createArticleSchema
       - `PATCH /api/admin/content/articles/:id` -- update article, requireRole('superAdmin', 'contentAdmin'), validate body with updateArticleSchema
       - `DELETE /api/admin/content/articles/:id` -- delete article, requireRole('superAdmin', 'contentAdmin')
       - `GET /api/admin/content/categories` -- list categories, requireRole('superAdmin', 'contentAdmin')
       - `POST /api/admin/content/categories` -- create category, requireRole('superAdmin')
       - `DELETE /api/admin/content/categories/:id` -- delete category, requireRole('superAdmin')

    3. Add Zod schemas to shared package:
       - `createArticleSchema`: validates all create fields, titleEn required (min 3, max 200), bodyEn and bodyBn as strings (Tiptap JSON), categoryId as UUID, tags as optional string array, cyclePhases as optional enum array, status as optional enum
       - `updateArticleSchema`: partial of createArticleSchema (all fields optional)

    4. Register content routes in admin router.
