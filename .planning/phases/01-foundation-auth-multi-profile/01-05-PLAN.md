    **Estimated: 2-3 developer-hours**

    1. Create account service (`services/account.service.ts`):
       - `deleteAccount(userId: string)`:
         - First: delete all Profiles for userId (Prisma cascade handles profile-scoped data)
         - Second: delete all VerificationTokens for userId
         - Third: delete the User record
         - Use Prisma transaction to ensure atomicity:
         ```typescript
         await prisma.$transaction([
           prisma.verificationToken.deleteMany({ where: { userId } }),
           prisma.profile.deleteMany({ where: { userId } }),
           prisma.user.delete({ where: { id: userId } }),
         ]);
         ```
         - Return confirmation
       - Note: Profile model has `onDelete: Cascade` on userId FK, so deleting User cascades to Profiles. But be explicit with transaction for safety and to handle future non-cascaded tables.

    2. Create account routes (`routes/account.routes.ts`):
       ```
       DELETE /api/account -> verifyJWT -> accountService.deleteAccount(req.user.id)
       ```
       - Requires authentication (user can only delete their own account)
       - Returns 200 with confirmation message
       - Clears refresh token cookie in response

    3. Mount in server.ts: `app.use("/api/account", accountRoutes);`

    4. Create account deletion tests (`__tests__/account.delete.test.ts`):
       - Setup: Create User with 2 Profiles and VerificationTokens
       - Test: DELETE /api/account returns 200
       - Test: After deletion, User record no longer exists in database
       - Test: After deletion, ALL Profiles for that user no longer exist
       - Test: After deletion, ALL VerificationTokens for that user no longer exist
       - Test: After deletion, attempting to use the same JWT returns 401 (user doesn't exist)
       - Test: Unauthenticated DELETE /api/account returns 401
