<objective>
Build the bilingual educational content platform: backend service with article CRUD and phase-based filtering, API routes for article listing and recommendations, frontend article browsing pages with category and cycle phase filters, a dashboard content feed widget showing phase-relevant articles, and seed data with 10-15 bilingual articles covering menstrual health, fertility, and Bangladeshi cultural context.

Purpose: Educational content drives engagement and addresses menstrual myths prevalent in Bangladesh. Phase-specific recommendations connect content to the user's current cycle state, making the platform contextually relevant rather than a static blog.

Output: Content API (list, filter, recommend), article listing and detail pages, dashboard content feed component, category filter UI, and seed articles ready for demo.
</objective>

    - getArticles with categoryId filters by category
    - getArticles returns { articles: ArticleResponse[], total: number, page: number, totalPages: number }
    - getArticleBySlug(slug, locale) returns single article with full body in correct language
    - getPhaseRecommendations(profileId, locale, limit) returns articles matching the profile's current cycle phase

  <action>
    **Estimated effort: 6 developer-hours**

    1. Create packages/api/src/services/content.service.ts:
       - getArticles(filter: ArticleFilter): Prisma query with:
         - where: status PUBLISHED, optional categoryId match, optional phase tag match (using phaseTags relation with { some: { phase: { in: [filter.phase, 'ALL'] } } })
         - select: locale-aware fields. ALWAYS return id, slug, coverImage, category, phaseTags, publishedAt. If locale is 'en': include titleEn, excerptEn. If locale is 'bn': include titleBn, excerptBn. Map to a unified ArticleResponse type (title, excerpt -- not titleEn/titleBn).
         - orderBy: publishedAt desc
         - Pagination: skip (page - 1) * limit, take limit
         - Return { articles, total (from count query), page, totalPages }
       - getArticleBySlug(slug: string, locale: 'en' | 'bn'): Single article with full body. Select locale-appropriate title, body, excerpt. Include category and phaseTags.
       - getPhaseRecommendations(profileId: string, locale: 'en' | 'bn', limit = 5):
         - Load latest prediction for profile
         - Calculate current cycle phase from prediction (use existing phase calculation utility from Phase 2)
         - Call getArticles with that phase and locale, limit to `limit` results
         - If no prediction data (new user), return articles tagged 'ALL'
       - getCategories(locale: 'en' | 'bn'): Return all categories with locale-appropriate name

    2. Create packages/api/src/routes/content.routes.ts:
       - GET /articles -- public endpoint (no auth required, content is public). Query params: categoryId, phase, locale (default from Accept-Language or 'en'), page (default 1), limit (default 10). Validates with articleFilterSchema.
       - GET /articles/recommendations -- requires auth (verifyJWT). Query params: profileId (from active profile), locale, limit. Returns phase-based recommendations.
       - GET /articles/:slug -- public. Returns single article by slug with locale query param.
       - GET /articles/categories -- public. Returns all categories for filter UI.
       - Export contentRouter

    3. Create packages/api/prisma/seed-content.ts:
       - Seed 5 categories: { slug: 'menstrual-health', nameEn: 'Menstrual Health', nameBn: 'মাসিক স্বাস্থ্য' }, { slug: 'fertility', nameEn: 'Fertility & Conception', nameBn: 'উর্বরতা ও গর্ভধারণ' }, { slug: 'nutrition', nameEn: 'Nutrition & Diet', nameBn: 'পুষ্টি ও খাদ্য' }, { slug: 'cultural-context', nameEn: 'Myths & Facts', nameBn: 'কিংবদন্তি ও তথ্য' }, { slug: 'wellness', nameEn: 'General Wellness', nameBn: 'সাধারণ সুস্থতা' }
       - Seed 12-15 articles across categories and phases:
         - 3 menstrual-health articles (tagged MENSTRUAL, FOLLICULAR, ALL)
         - 3 fertility articles (tagged OVULATORY, LUTEAL, ALL)
         - 2 nutrition articles (tagged ALL)
         - 3 cultural-context articles (tagged ALL) -- addressing Bangladeshi menstrual myths (CONT-05): myth about not bathing during periods, myth about food restrictions, myth about exercise during menstruation
         - 2 wellness articles (tagged ALL)
       - Each article has bilingual title, excerpt, and body (body can be 2-3 paragraphs of placeholder text in both languages)
       - All seeded articles set to PUBLISHED status
       - Script is idempotent (upsert by slug)

    4. Write tests in packages/api/src/__tests__/content.service.test.ts:
       - Test getArticles returns only PUBLISHED articles
       - Test getArticles with phase FOLLICULAR returns articles tagged FOLLICULAR and ALL (not LUTEAL)
       - Test getArticles with categoryId filters correctly
       - Test getArticles pagination returns correct page/totalPages
       - Test getArticleBySlug returns correct locale fields (en locale -> title from titleEn)
       - Test getPhaseRecommendations uses profile's current phase
       - Test getPhaseRecommendations for profile with no prediction returns ALL-tagged articles
       - Mock Prisma client for unit tests
