# Cycle Circle v2.0.0

Building on **v1.5.0**, the product is renamed from Vesta to **Cycle Circle** with a new visual identity. The rename is user-facing only. See [ADR 0001](../adr/0001-cycle-circle-rename-is-user-facing-only.md) and [GLOSSARY.md](../../GLOSSARY.md).

**Deployed:** Contabo VPS via Docker Compose, now released from the `production` branch by GitHub Actions. Images build on Node 24. No new database migrations.

Specs: [#18 Cycle Circle rebrand](https://github.com/adibahsan/cycle-circle/issues/18) and [#30 UI cleanup](https://github.com/adibahsan/cycle-circle/issues/30) (PR [#50](https://github.com/adibahsan/cycle-circle/pull/50)).

---

## Highlights

### Brand and identity

- **Name**: all user-facing copy, English and Bengali, now says Cycle Circle. Page metadata, titles and descriptions follow.
- **Logo and icons**: new Cycle Circle logo and drop mark, favicon, app icons and OG image.
- **Design tokens**: new Cycle Circle palette, fonts and goal accents in the shared `globals.css`. The Button is now a pill, and Input has an error state.
- **Contact details**: new contact keys and a shared contact block used in the footer and legal pages.

### Web app

- **App shell, dashboard and calendar** restyled with the new tokens, including the flow pills.
- **Landing page and legal pages** (privacy, terms) rebranded.
- **Subscription paywall and auth screens** rebranded.
- **Remaining signed-in screens, onboarding and modals** moved onto tokens.

### UI cleanup (spec #30)

- **One pop-up shell**:
  - Every pop-up in web and admin uses it.
  - ESC closes the top pop-up, focus stays inside and returns to the trigger, and the page behind doesn't scroll.
  - Pop-ups are bottom sheets on phones and centred cards on larger screens, with named layers.
  - The trial "add number" dialog now opens over the whole screen (P0).
  - The save celebration is a polite toast.
- **Auto-prompts**: at most one per page load. Priority order: trial lock, late-period alert, tour, check-in, then the profile prompt. Each has a daily or 3-day cadence on the Bangladesh (UTC+6) day.
- **Phone layout**: a 5-slot bottom nav, a More sheet, and a compact header with a profile chip. No page scrolls sideways at 375px.
- **Page layout**: one shared page header and container, so titles, edges and spacing line up. Text is at least 11px.
- **Dark mode**:
  - The theme applies before first paint, with no white flash.
  - Focus rings sit on the surface colour.
  - Surfaces, borders and tints are retuned and contrast-tested.
- **One home per prompt**:
  - The profile-completion banner is gone, replaced by a ring on the profile chip and a single dashboard row.
  - Check-in lives on the streak strip.
  - The logging nudge appears on the dashboard only.
- **Fixes**:
  - `/profiles` no longer fails hydration.
  - The calendar's "This Cycle" fertile window matches the dashboard.
  - The landing page is visible without JavaScript.
- **Copy**: hard-coded English moved into i18n with Bengali.
- **Admin**: the same pop-up shell, pre-paint theme and focus rings. The email preview is readable in dark mode, and status colours are contrast-tested.

### Delivery

- **Release branch**: `production` deploys through GitHub Actions. Checks run first, then the database is backed up, images are built, migrations applied, and web and admin restarted with live-site checks. See `docs/ops/03-deployment.md` §5.
- **Node 24** for the production images, dev images and CI.
- **Tests**: a local Playwright suite (`pnpm --filter @vesta/web e2e`, 161 tests) guards pop-ups, phone overflow and Bengali copy. The web vitest suite has 790 tests.

### Admin app

- Admin wordmark, a token-driven chart palette and brand focus rings. Chart status colours stay semantic (success, warning, error).

### Email

- Transactional email templates use the Cycle Circle palette, a logo header and a contact footer.

## Intentionally still `vesta`

Per ADR 0001, these keep the old name on purpose. A `vesta` string in code is expected, not a missed rename.

- Package scope `@vesta/*` and `VESTA_*` environment variables.
- Cookie names and localStorage / sessionStorage keys, so no user is logged out.
- Component and file names.
- Docker, database and VPS names (for example `/opt/vesta`).
- Domains and the sender address.
- BDApps simulator strings.

## Known follow-ups

- The Bengali copy needs a native-speaker spot-check.
- Three light-theme text pairs from the spec palette miss WCAG AA. Primary and gold-ink are therefore used as text only on card and page backgrounds.
- The `privacy.sections.contact.email` i18n key is unused.
- In Bengali, signed-in pages hit a hydration mismatch, because the language is read from localStorage while the server renders English. The pages recover on the client.
- `/api/auth/dev-login` is gated only by `DEV_MODE`. Production runs with `DEV_MODE=true` for now, by choice.
- `.glass` has no blur in Chromium, because the Tailwind v4 build drops the unprefixed `backdrop-filter`.
