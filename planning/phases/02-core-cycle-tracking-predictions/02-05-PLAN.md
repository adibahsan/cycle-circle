    **Cycle Query Hooks (packages/web/src/api/cycles.ts):**

    Create TanStack Query hooks following the pattern from profiles.ts:
    - `useCycles(profileId)` -- GET /profiles/:pid/cycles, queryKey: ['cycles', profileId], enabled: !!profileId
    - `useLogPeriodStart(profileId)` -- POST mutation, on success invalidate ['cycles', profileId] AND ['predictions', profileId]
    - `useLogPeriodEnd(profileId)` -- PATCH mutation to /:cycleId/end, on success invalidate ['cycles', profileId] AND ['predictions', profileId]
    - `useUpdateCycle(profileId)` -- PUT mutation to /:cycleId, on success invalidate same keys

    **Prediction Query Hooks (packages/web/src/api/predictions.ts):**

    - `usePrediction(profileId)` -- GET /profiles/:pid/predictions, queryKey: ['predictions', profileId], staleTime: 5 minutes (predictions don't change frequently)
    - `useMultiPredictions(profileId, count=3)` -- GET /profiles/:pid/predictions/multi?count=3, queryKey: ['predictions', 'multi', profileId, count]

    **Derived Hooks:**

    `useCycleDay(profileId)`:
    - Fetches: useCycles(profileId) to get the most recent cycle's startDate, usePrediction(profileId) to get predicted cycle length
    - Gets the profile's average period length from useActiveProfile
    - Computes: cycleDay = getCycleDay(lastPeriodStart, today), phase = getCyclePhase(cycleDay, periodLength, predictedCycleLength), daysUntil = getDaysUntilNextPeriod(cycleDay, predictedCycleLength)
    - Returns: { cycleDay, phase, daysUntilNextPeriod, isOnPeriod, lastPeriodStart, predictedCycleLength, isLoading, error }

    `useFertileWindow(profileId)`:
    - Uses usePrediction to get current prediction
    - Computes: fertileWindowStart, fertileWindowEnd, ovulationDate, isCurrentlyFertile (today is within window), isOvulationDay
    - Returns: { fertileWindowStart, fertileWindowEnd, ovulationDate, isCurrentlyFertile, isOvulationDay, isLoading }

    All hooks use shared constants/phases.ts pure functions for computation. No duplicated cycle math in the frontend.
