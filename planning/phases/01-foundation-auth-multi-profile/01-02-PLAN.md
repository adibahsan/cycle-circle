    3. Create auth service (`services/auth.service.ts`):
       - `register(data)`: Validate email uniqueness, hash password with Argon2id (memory: 19456 KiB, iterations: 2, parallelism: 1), create User, create VerificationToken (type: "email_verification", expires: 24h), send verification email via Resend, return user + access token + set refresh cookie
       - `login(data)`: Find user by email, verify password with argon2.verify, generate access token (15min expiry, payload: { userId, role }), generate refresh token (7d expiry, payload: { userId, tokenVersion }), set refresh token as HttpOnly cookie (path: /api/auth/refresh, secure: NODE_ENV=production, sameSite: strict)
       - `refresh(refreshToken)`: Verify refresh token, check tokenVersion matches User.tokenVersion (for invalidation), rotate: increment tokenVersion, issue new access + refresh tokens
       - `verifyEmail(token)`: Find VerificationToken, check not expired and not used, set User.isVerified = true, mark token usedAt
       - `forgotPassword(email)`: Find user, create VerificationToken (type: "password_reset", expires: 1h), send reset email
       - `resetPassword(token, newPassword)`: Find token, verify not expired/used, hash new password, update User.passwordHash, increment tokenVersion (invalidates all existing sessions), mark token used

    1. Create API client with token refresh mutex (`api/client.ts`):
       ```typescript
       const API_BASE = import.meta.env.VITE_API_URL || "";
       let accessToken: string | null = null;
       let refreshPromise: Promise<string> | null = null;

       async function refreshAccessToken(): Promise<string> {
         if (refreshPromise) return refreshPromise;
         refreshPromise = fetch(`${API_BASE}/api/auth/refresh`, {
           method: "POST",
           credentials: "include",
         })
           .then(res => { if (!res.ok) throw new Error("Refresh failed"); return res.json(); })
           .then(data => { accessToken = data.data.accessToken; return accessToken!; })
           .finally(() => { refreshPromise = null; });
         return refreshPromise;
       }

       export async function apiClient<T>(path: string, options: RequestInit = {}): Promise<ApiResponse<T>> {
         // First attempt with current access token
         // On 401, attempt refresh, retry once
         // On second 401, redirect to login (clear auth state)
       }
       ```
